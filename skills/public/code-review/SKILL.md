# Code review procedure

1. Restate in one sentence what the code is supposed to do.
2. List concrete bugs first (wrong behaviour, crashes, edge cases), each with the line or snippet.
3. Then list design or readability problems, most important first.
4. For each problem, give a short suggested fix.
5. End with a one-line verdict: ship, fix first, or rewrite.

Do not nitpick formatting unless it hides a bug.
